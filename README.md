# Minhas Contas

Aplicação web responsiva para registrar contas e despesas mensais, acompanhar vencimentos e visualizar resumos por categoria.

## Executar localmente

Abra `index.html` no navegador. Os lançamentos são persistidos no `localStorage` do navegador, permitindo testar o fluxo sem configurar um servidor.

## Próximos passos para produção

1. Migrar a persistência para Supabase/PostgreSQL e adicionar autenticação.
2. Criar um repositório no GitHub e enviar estes arquivos.
3. Importar o repositório na Vercel para obter deploy automático.

Esta versão inicial já possui cadastro, edição, exclusão, filtros, dashboard, status de vencimento, limite mensal, tema escuro e exportação CSV.

Deploy sincronizado com a branch master.
